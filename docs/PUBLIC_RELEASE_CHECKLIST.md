# Open-source preview / stable-readiness checklist

The owner authorized a public source release on 2026-09-04. Version 1.9.0
uses MIT for original code and retains upstream licenses. This is an
experimental community preview, not a completed certification program.

## Publication essentials

- Owner-authorized license and no institutional endorsement.
- Secret and personal-data scan of current files and reachable Git history.
- No pairing material, private addresses, ride traces or signing keys in
  downloadable packages.
- Functional builds and targeted regression checks.
- Clear privacy, network-access and experimental-estimation disclosures.
- Exact release checksums and honest platform support matrix.

## Still required before a stable/security-reviewed designation

- Independent authentication, remote-execution and WebView security review.
- Broad Android OEM lock-screen/battery-optimization and iOS device testing.
- Real-world battery-model calibration and held-out error evaluation.
- Reproducible clean CI builds, SBOM/provenance attestations and signed
  Windows releases.
- Formal trademark/legal review, support lifecycle and recovery drills.

Do not infer these remaining checks have passed from repository visibility.
