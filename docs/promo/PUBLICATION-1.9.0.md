## Getting started

Install the 1.9.0 Android APK, open **Commute → Scooter**, configure the charger location and notification preferences, then mark a real full charge. Start and stop each ride explicitly. Allow location and notification permissions for the Android recording service. Mark depleted only when the battery was actually depleted. Do not intentionally run out of power somewhere unsafe for calibration.

Battery percentage and return-range warnings are estimates, not direct battery telemetry. Missing or stale location/routing data must not be interpreted as sufficient charge.
