# 我把手机遥控电脑，做成了通勤工作台

每天出门前，总要想一遍：今天坐车，还是骑 Scooter？
骑到一半又开始担心：剩下的电，够不够回充电的地方？

所以我给自己的远程工作台加了一个“通勤 + Scooter”页面。

手机上能看电脑任务、处理远程操作，也能比较通勤方式。
Scooter 部分，充满后点一下，出发和停车各点一下，就能按充电周期累计里程、
时间和爬升。再结合地图上的返回路线，提醒我留足回程余量。

现在刚开始积累真实数据，电量只是估算，不是读取车上的电池表。
记录越完整，才越有机会校准得更好；不会因为用了两周就突然“百分百准确”。

我把整个项目放到 GitHub 开源了，MIT 许可。
电脑里的任务、配对信息和个人轨迹不在开源包里。

项目：CCMKCCMK / Codex-LAN-Console
